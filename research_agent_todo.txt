Research Agent Implementation Checklist

2. Replace the broken quiz tool
   - Make the quiz tool accept a topic.
   - Load the relevant saved learning records.
   - Generate questions from learned material.
   - Track the user's answers, score, and weak concepts.

3. Store learning and research data structurally
   - Replace free-form log entries with structured JSON or SQLite records.
   - Store topics, concepts, summaries, statuses, timestamps, confidence, and quiz results.
   - Keep source URLs and citation metadata with each learning record.

4. Enforce citations in research summaries
   - Require every researched claim to include a source citation.
   - Store source title, URL, and the claims supported by each source.
   - Do not present unsupported facts as verified findings.

5. Persist research milestones
   - Break each research request into named milestones.
   - Track each milestone as planned, researching, complete, or needs-review.
   - Resume unfinished milestones in later conversations.
   - Record open questions and next steps.

6. Add error handling and tests
   - Handle missing API keys, network failures, rate limits, invalid search results, and file/database errors.
   - Validate tool inputs and reject empty queries or notes.
   - Add focused tests for web search, persistence, citations, milestone tracking, and quizzes.

8. Add reliable durable memory
   - Store durable user facts, preferences, project decisions, and important research conclusions separately from the raw conversation transcript.
   - Extract important facts from user messages and save them in structured SQLite records.
   - Retrieve relevant memories before each model call and inject them into the model context.
   - Preserve memory across long conversations even when older messages are trimmed or summarized.
   - Do not rely on the model searching the full checkpoint transcript to remember facts.
   - Add tests that save a fact, continue for many turns, and verify that the fact is recalled and applied correctly.
